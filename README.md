# Tic-Tac-Toe

A browser-based Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## Features

- Two-player gameplay
- Player name input
- X and O turn handling
- Winner detection
- Tie detection
- Winning-box highlighting
- Score tracking
- New game functionality

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Play

1. Enter the names of both players.
2. Player 1 plays as X.
3. Player 2 plays as O.
4. Players take turns selecting a square.
5. The first player to get three symbols in a row wins.
6. If all squares are filled without a winner, the game ends in a tie.
